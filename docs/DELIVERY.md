- **需求 100% 覆盖**：41/41，无丢弃。与第 0 阶段那版的关键区别——那版用"别抄四样"砍掉了 Mandate / Gate / 槽位 / 扇出，本版全部保留。

- **任务覆盖架构**：`TASKS.md` 的 14 个任务把详设的 15 个源文件与 1,300 行逐项认领，依赖边构成拓扑序（K01 → 纯函数域 → 存储/副作用 → 组合根 → 执行器/通道/面板 → 测试 → 端到端），无悬空依赖（机检 ⑥ 已验证）。
